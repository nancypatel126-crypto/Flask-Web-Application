
# Flask Web Application

## Description
A simple and responsive web application developed using Python Flask, HTML, and CSS.

## Features
- Home Page
- About Page
- Contact Page
- Flask Routing
- HTML Templates
- CSS Styling
- Responsive Design

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Installation

Install Flask:

```bash
python -m pip install -r requirements.txt
```

## Run Application

```bash
python app.py
```

Open in browser:

http://127.0.0.1:5001/
